# 🎬 OBS VOD Clip Extractor

A lightweight, automated desktop utility built to bridge the gap between live streaming and high-speed video editing. Instead of forcing you to re-watch hours of video footage just to find your best gaming highlights, this application automatically parses timestamp logs and extracts high-quality clips directly from your processed YouTube VODs in seconds.

By leveraging the raw downloading power of `yt-dlp` and the fast media-cutting capabilities of `FFmpeg`, the app completely bypasses the need for manual screen recording or heavy, slow video-editing software.

## 🛠️ How It Integrates with OBS (Local Stream Markers)
This tool is explicitly designed to work seamlessly alongside the local OBS Stream Marker Lua script added to OBS Studio.

1. **During Your Live Stream:** You play your game. When a cool moment happens, you hit your assigned OBS hotkey.
2. **Behind the Scenes:** The OBS script immediately grabs the exact timestamp relative to the live broadcast timeline and saves it to a local file.
3. **Post-Stream Extraction:** You feed that exact marker file into this extractor app. It applies **auto-rewind math** (automatically targeting the 60 seconds *before* your button press) to make sure your clip includes the full build-up and climax of the action.

## 📊 Managing the CSV File & Custom Names
The extractor processes standard Comma-Separated Values (`.csv`) files perfectly. You can use the file completely raw as generated by OBS, or you can open it in **Google Sheets, Microsoft Excel, or Notepad** before running the program to organize your content.

* **Generic Naming (Default):** If you leave the file as-is, the program automatically tracks and downloads your files sequentially as `clip_1.mp4`, `clip_2.mp4`, etc.
* **Custom Naming (Optional):** If you want to check your timestamps and organize them manually, simply type your custom clip name directly into **Column B** (or right after the first comma in a text editor). 

### Example CSV Sheet Layout:
| Column A (Timestamps) | Column B (Your Custom Clip Name) |
| :--- | :--- |
| `0:16:00` | cool_truck_clip |
| `0:27:05` | long_bridge_clutch |
| `0:48:34` | Foxes |

*Note: This release includes a robust formatting fix that automatically handles single-digit hour shifts (e.g., smoothly reading `0:16:00` vs `01:16:00` without throwing errors).*

## 📦 Installation & Quick Setup

### Option A: The Standalone Installer (Recommended)
Head over to the **[Releases Tab](https://github.com/vic1175/VOD-Clips-Generator/releases)** and download `OBS_VOD_Clip_Extractor_Setup.exe`.
1. Run the installer (grant Administrator privileges when prompted).
2. The setup wizard automatically installs the application, generates a desktop shortcut, and handles configuring the background `FFmpeg` video engine paths silently.
3. Launch the desktop app via your new desktop icon and start clipping!

### Option B: Running via Source Code (Developers)
If you prefer running the script directly through your local environment:
1. Download `clip_generator.py` from this repository.
2. Ensure you have **Python 3.x** installed.
3. Install the required dependencies via your terminal:
   ```bash
   pip install yt-dlp
4. Ensure you have an ffmpeg.exe binary located specifically at C:\ffmpeg\bin\ffmpeg.exe.
